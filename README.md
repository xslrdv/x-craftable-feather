# 💣 X Craftable Feather

A vanilla-friendly **Minecraft** mod for **NeoForge** that adds a logical and balanced full crafting cycle for a **Feather Blank**. Shred *Sugar Cane* with *Shears* into **Cane Fibers**, extract a **Tar Clump** by smelting *Coal*, assemble a **Feather Blank**, and smelt it into a vanilla *Feather* - all without *harming* a single *animal*.

---

## ✨ Features

* **Cane Fibers Extraction**
  * Combine *Sugar Cane* with *Shears* in a crafting grid to shred it into **Cane Fibers**.
* **Tar Clump Extraction**
  * Smelt *Coal* (or *Charcoal*) in a **Furnace**, **Blast Furnace**, or **Smoker** to extract a **Tar Clump**.
* **Feather Blank**
  * Assemble a **Feather Blank** by combining *Sugar Cane*, **Cane Fibers**, and a **Tar Clump**.
* **Curing & Smelting** to **Vanilla Feather**
  * Process a **Feather Blank** in a **Furnace**, **Blast Furnace**, **Smoker**, or over a **Campfire** to produce a standard vanilla **Feather**.

---

## 💡 Why X Craftable Feather?

- **Vanilla-Friendly & Balanced**: Carefully tuned recipes that respect early- and mid-game survival progression.
- **Fair Resource Trade-off**: Uses tool durability, agricultural crops, and multi-step crafting, making *Feather* production earned, not given.
- **Peaceful Alternative**: Provides a sustainable, plant-based way to obtain *Feathers* for arrows, books and quills, and fletching *without needing to kill chickens*.
- **Intuitive Mechanics**: Uses logical, real-world-inspired steps (*shredding cane fibers*, *extracting tar*, *curing feather blanks*) that blend seamlessly into vanilla gameplay.

## 🛠️ Installation & Requirements

### Requirements
1. **Minecraft**: `26.3`
2. Mod Loader: **NeoForge** `26.3.0.95+`

### Installation
1. Download and install **NeoForge** (version `26.3.0.95` or higher) for **Minecraft** `26.3`.
2. Download the latest release of **X Craftable Feather**.
3. Place the `.jar` file into your `.minecraft/mods` folder.
4. Launch the game and enjoy!
